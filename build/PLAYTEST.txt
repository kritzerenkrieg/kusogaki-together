Kusogaki Together - play test build

HOW TO START
  Windows: unzip, open the folder, run "Kusogaki Together.exe".
           If SmartScreen warns: More info -> Run anyway (the build is not signed).
  macOS:   unzip, move "Kusogaki Together.app" to Applications. The build is not
           signed, so the first time open Terminal and run:
               xattr -cr "/Applications/Kusogaki Together.app"
           then open it normally.
  Linux:   chmod +x kusogaki-together-*-linux-x86_64.AppImage, then run it.
           (No FUSE? Run it with --appimage-extract-and-run.)

PLAYING TOGETHER
  Set your name in Options first. One player picks Multiplayer, then Create room.
  Everyone else picks Multiplayer and joins that room from the list (a private
  room: Join by room ID, with the 6-digit ID the waiting room shows). In the
  waiting room the host picks the level and presses Start. When the level is
  over the host presses Enter to bring everyone back to the room.
  Everyone needs the same build.
  Relay only (when creating a room) hides everyone's IP address from the others
  (a little more lag).

The game starts fullscreen; ESC leaves a game.
